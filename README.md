# Calisthenics AI Coach

## מה כלול
- נגן וידאו מקומי להעלאת סרטון.
- Pose Landmarker של MediaPipe לזיהוי נקודות גוף והצגת שלד.
- חישובי זוויות והערות בסיסיות מקומיות.
- PWA: אפשרות התקנה במסך הבית.

## הפעלה
יש להעלות את כל הקבצים לאותו תיקייה בשירות אירוח שתומך ב-HTTPS, למשל GitHub Pages או Vercel.
לאחר הפרסום פותחים את כתובת האתר ב-Chrome באנדרואיד ובוחרים בתפריט ⋮ > התקנת אפליקציה / הוספה למסך הבית.

לבדיקה במחשב אפשר להריץ שרת מקומי מתוך התיקייה:
`python -m http.server 8000`
ואז לפתוח `http://localhost:8000`.
פתיחה ישירה של index.html באמצעות file:// לא תפעיל PWA או Service Worker.

## חשוב לדעת
- בטעינה הראשונה נדרש אינטרנט כדי להוריד את MediaPipe ואת קובץ המודל.
- זיהוי השלד וחישובי המדדים מתבצעים בדפדפן. הסרטון לא נשלח לשרת.
- המשוב הנוכחי הוא חוקים גאומטריים ראשוניים, לא מודל שפה ולא מאמן מומחה. הציון הוא אינדיקציה טכנית בלבד ואינו ציון מקצועי תקף.
- ביצועים תלויים במכשיר, באורך הסרטון, בתאורה, בזווית הצילום ובכך שכל הגוף נראה בפריים.
- בגרסה הזו מומלץ סרטון קצר (עד כ-30–45 שניות) וצילום צדדי. אין להסתמך על המדדים לקבלת החלטות רפואיות או למניעת פציעות.
- כדי להוסיף בעתיד AI שיחתי מתקדם נצטרך שירות AI חיצוני, שעשוי להיות בתשלום. אין להכניס מפתח API לקוד שבדפדפן.
